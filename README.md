# 🧋 Yummy Tea - E-Commerce Frontend

Welcome to **Yummy Tea**, a vibrant and fully responsive e-commerce frontend built for a premium bubble tea shop. This project focuses on delivering a smooth, aesthetic, and user-friendly shopping experience with dynamic, interactive UI elements.

## 🌸 About the Project

Yummy Tea isn't just a static bubble tea menu—it's a fully interactive digital storefront. The application features a custom UI designed to capture the fun, inviting atmosphere of a modern boba shop. It includes a working slide-out cart, dynamic product detail modals, and a responsive checkout system that adapts flawlessly across mobile, tablet, and desktop screens. 

The entire interface is powered by Vanilla JavaScript, ensuring fast performance and smooth DOM manipulation without the need for heavy frameworks.

## ✨ Key Features

- **Fully Responsive Design:** Pixel-perfect layouts adapted for Mobile (max 768px), Tablet (768px - 1024px), and Desktop viewports.
- **Dynamic Slide-Out Cart:** Users can add items, remove items, and automatically calculate total prices in real-time using Vanilla JavaScript.
- **Interactive Product Modals:** Clicking a product opens a detailed modal with descriptions, pricing, and quantity selectors.
- **Smart Checkout UI:** A dynamic checkout form that toggles required fields based on the user's choice of "Delivery" or "Take Away".
- **Modern UI/UX:** Features smooth CSS animations, hover effects, floating decorative elements, and a custom scroll-to-top button.
- **Zero Dependencies:** The frontend interactivity is built entirely with clean, vanilla JavaScript (No jQuery or external JS libraries).

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and accessibility.
- **CSS3:** Flexbox, CSS Grid, custom keyframe animations, and media queries for responsive design.
- **Vanilla JavaScript:** DOM manipulation, event handling, and array methods for cart logic.
- **FontAwesome:** Scalable vector icons.
